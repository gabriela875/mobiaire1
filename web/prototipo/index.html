Fuentes, proyecto y aviso.

Fuentes integradas

WAQI / World Air Quality Index Project: datos recientes de calidad del aire (índice en escala US-EPA). Atribución obligatoria.

Observatorio Ambiental de Bogotá (OAB) / Red de Monitoreo (RMCAB): estaciones oficiales de la ciudad, servidas a través de WAQI.

IDEAM / SISAIRE (dataset g4t8-zkc3): datos históricos para validar el motor ICA del proyecto.

El proyecto

MobiAire Materno — semáforo informativo de calidad del aire para gestantes de Ciudad Bolívar. Universidad Distrital Francisco José de Caldas.
